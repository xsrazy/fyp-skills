# Multi-Platform Caption

One video, five platforms, five different captions. Each platform rewards different text: TikTok search reads captions, Instagram rewards saves and shares, Facebook favors plain product names and conversation, YouTube Shorts titles do the discovery work, Shopee is a storefront, not a feed.

## Inputs to collect first

- What the video shows (required): product name or topic, the key moment, the result or payoff.
- Product link or store name, if it is a selling video.
- Language: default Bahasa Indonesia. Hashtags follow the platform norms below.

## Per-platform rules

### TikTok
- Caption: 1-2 short lines, written for search. Include the words a buyer would type (product name, use case, problem it solves).
- 3-5 hashtags: product name first, then category, then one broad trending tag. No hashtag walls.
- If the video has a shopping basket, the caption must name the exact product variant shown.

### Instagram Reels
- Caption: product name or topic as the first line, plain. One short supporting line is allowed; links do not work in captions, so never paste one.
- 3-5 hashtags max, specific over broad.
- Remember the format is 9:16; if the user mentions cropping issues, note it, do not solve it here.

### Facebook Reels
- Caption: product name only, or one plain descriptive line. Facebook audiences here skew older; write plainly, no slang pile-up.
- Affiliate or product links belong in the platform's affiliate link field, not in the caption text. Remind the user of this when a link is provided.

### YouTube Shorts
- Title does the work: under 60 characters, front-load the searchable phrase, no clickbait the video cannot pay.
- Description: 1-2 lines plus 2-3 hashtags. Include #Shorts only if the user wants it.

### Shopee Video
- Title: product name exactly as listed in the store, plus one benefit word. This is a shelf label, not a hook.
- No external links, no directing buyers off-platform.

## Rules for all platforms

- Never invent prices, discounts, or claims. Numbers come from the user or the video.
- Never reuse the same caption verbatim across platforms; rewrite each one.
- Keep each caption paste-ready: no placeholder brackets left in the final output.
- If the video is not a selling video, drop the Shopee section and say so.

## Output format

Five labeled sections (TikTok, Instagram, Facebook, YouTube, Shopee), each containing only the paste-ready text. No explanations inside the sections; brief notes, if needed, go after all five.
